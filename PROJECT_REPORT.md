# Customer Segmentation - Project Report

## Objective
Group customers into meaningful segments using unsupervised machine learning.

## Method
Annual Income and Spending Score are standardized and evaluated with K-Means. Candidate K values are compared using silhouette score, and the best K is selected.

## Tools
Python, Pandas, Scikit-learn, Matplotlib.

## Outputs
- segmented_customers.csv
- cluster_summary.csv
- customer_clusters.png
- silhouette_scores.png
- project_results.txt
